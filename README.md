# aplikasi-distribusi-jadwal-sembako

## Deskripsi
Aplikasi mobile berbasis Android untuk mengelola penjadwalan distribusi sembako, yang menjawab masalah proses distribusi yang masih dilakukan secara manual. Sistem melibatkan tiga aktor: Pemasok, Pelanggan dan Kurir.

## Anggota Tim
- Arif — Peran
- Yuspa — Peran
- Falih — Peran
- Abi — Peran
- Andika — Peran

## Teknologi
- PHP
- MySQL/MariaDB
- HTML, CSS, dan Bootstrap

## Struktur Dokumentasi
- docs/SDD: dokumen desain perangkat lunak
- docs/STD: dokumen pengujian perangkat lunak

## Persiapan
1. Clone repository.
2. Siapkan web server dan database lokal.
3. Buat database sesuai skrip di folder database.
4. Sesuaikan konfigurasi database lokal.

## Catatan
Petunjuk instalasi dan penggunaan akan diperbarui
sesuai perkembangan proyek.
